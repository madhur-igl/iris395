# Iris Flower Classification 🌸

A Machine Learning project that classifies Iris flowers using **Logistic Regression**.

## 📌 Project Overview

This project uses the famous Iris dataset to train a Logistic Regression model.

The model predicts the species of an Iris flower based on four measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 🤖 Machine Learning Model

**Algorithm:** Logistic Regression

The dataset is divided into:

- 80% Training data
- 20% Testing data

## 📊 Evaluation Metrics

The model is evaluated using:

- Accuracy
- Precision
- Recall

## 📁 Project Files

| File | Description |
|---|---|
| `Iris.csv` | Iris dataset |
| `train.py` | Code used to train the model |
| `iris_model.pkl` | Saved trained model |
| `predict.py` | Code used to make predictions |
